# 🛵 seoul-delivery

서울 배달 라이더 · 1인칭 오토바이 — 브라우저에서 바로 달리는 3D 배달 게임입니다.

남산타워가 보이는 서울의 밤거리에서 1인칭 오토바이를 몰고 주문을 받아
픽업하고 배달합니다. 신호를 지키고 음식을 따뜻하게 가져다주면 별점이 올라갑니다.

## 플레이

- 웹: <https://sungjin513-dev.github.io/seoul-delivery/>
- 로컬: `index.html` 파일을 브라우저로 열면 됩니다.

## 조작

| 동작 | 모바일 | PC |
| --- | --- | --- |
| 좌우 핸들 | ◀ ▶ 버튼 | A/D, ←/→ |
| 가속 / 감속 | 악셀 / 브레이크 버튼 | W/S, ↑/↓ |
| 경적 | 빵빵 버튼(누르고 있으면 계속) | Space |
| 방향지시등 | ◀/▶ 깜빡이 버튼(한 번 더 누르면 소등) | Q/E (또는 Z/C) |
| 배차판 | 상단 `📱 배차판` 버튼 | 마우스 클릭 |
| 지도 | 미니맵 탭 → 전체 지도, 그 아래 `🧭 내비 / N 북고정` | 마우스 클릭 |
| 차고/탈것 상점 | 상단 차고 버튼 · 정산 화면 버튼 | 마우스 클릭 |

정차하면 가게 앞에서 `[음식 받기]`, 고객 앞에서 `[음식 건네주기]` 버튼이 뜹니다.
버튼을 누르면 손을 뻗어 봉투를 직접 주고받는 연출과 함께 픽업/배달이 진행됩니다.
빨간불에서는 정지선 앞에 서고, 회전 전에 깜빡이를 켜면 매너 보너스가 붙습니다.
경적을 울리면 앞의 보행자는 놀라 멈칫하며 차도에서 물러나고, 앞차는 브레이크등을 켜고 감속합니다.

## 자유 주행 (프리 라이드)

게임을 시작하면 배차판이 화면을 막지 않고 **바로 자유 주행**으로 출발합니다.
콜이 없어도 조향·가속·브레이크·경적·깜빡이·지도·차고를 그대로 쓰며 서울 거리를 달릴 수 있고,
돌아다니다 **⛽ 주유소**와 **🏪 편의점**에 들러 연료·배고픔을 채울 수 있습니다.

- 상단 `📱 배차판` 버튼(콜 건수 배지)을 누르면 언제든 배차판이 열립니다. 2~3건 중 골라 `[수락]`하면 배달 시작.
- 배차판은 오른쪽 위 `✕` 또는 아래 `[🏍 자유 주행]`으로 닫고 계속 달릴 수 있습니다(콜 목록은 그대로 유지).
- 배달을 마친 정산 화면에서도 `[🏍 자유 주행 · 콜 없이 달리기]`로 바로 거리로 나갈 수 있습니다.
- 자유 주행 중에는 음식이 없으므로 신호위반·충돌·과속방지턱은 **경고 안내만** 뜨고 정산에 영향이 없습니다.
  배달을 받으면 기존 규칙(픽업 → 건네주기 → 정산)이 그대로 적용됩니다.

## 신호 · 우회전
- 빨간불에 교차로로 들어가면 신호위반입니다. 단, **오른쪽으로 회전해 교차로를 빠져나가면 우회전으로 인정**되어
  통과할 수 있습니다(배달 정산 감점 없음). 직진·좌회전은 그대로 위반입니다.
- 진입 때 신호를 한 번 래치하고 **교차로를 완전히 빠져나가는 순간의 진행 방향**으로 판정하므로,
  교차로 안에서 좌회전하며 축이 바뀌어도 오판하지 않습니다.

## 배차판 · 음식 특성

콜은 한 번에 **2~3건**이 배차판에 뜨고, 카드를 눌러 고른 뒤 `[수락]`하면 출발합니다.
콜마다 가게·총 거리·기본 배달료와 음식 특성 태그가 붙습니다.

| 태그 | 단가 | 흔들림 |
| --- | --- | --- |
| 🍲 국물 주의 · 흔들림 민감 | +₩800 | 과속방지턱·급정거에 민감 |
| ☕ 음료 · 급정거 주의 | +₩600 | 가장 민감 |
| 🍗 튀김 · 온도 유지 | +₩300 | 온도가 빨리 떨어짐 |
| 🍱 도시락 · 기본 배달 | – | 표준 |

## 과속방지턱 · 연료 · 배고픔

- 도로 차로마다 노란/검정 **과속방지턱**이 있습니다. 19km/h 이하로 넘으면 음식이 안전하고,
  빠르게 넘으면 `덜컹!` 흔들림과 함께 음식 상태가 깎입니다(국물·음료는 더 민감).
- HUD의 **⛽ 연료 게이지**는 주행할수록 줄어들고(4~5건마다 한 번 주유할 정도),
  연료가 0이 되면 비상 저속 주행으로 바뀝니다. 지도에 표시된 ⛽ 주유소에 정차하면
  `[주유하기]` 버튼이 떠서 보유 수익으로 만땅(₩1,500) 채울 수 있습니다.
  잔액이 부족하면 35%까지 무료 응급 주유가 됩니다.
- **🍚 배고픔 게이지**도 천천히 줄어듭니다. 22% 이하가 되면 "배고파요" 안내가 뜨고
  0%가 되면 최고속도만 조금 줄어듭니다(게임이 멈추지는 않음).
  🏪 편의점에 정차해 `[편의점 들르기]`로 삼각김밥(₩1,500)·컵라면(₩2,200)·
  도시락(₩4,500)을 먹으면 배고픔이 회복됩니다(잔액 부족 시 무료 응급 간식).

## 날씨 · 지도

- 상단 `낮 / 노을 / 밤 / ☔비` 4종 전환. 비가 오면 빗줄기·젖은 노면·헬멧 바이저 물방울이
  나타나고 노면이 미끄러워지며(그립·제동거리 변화), 정산에 **우천 할증(+₩760~1,000)**이 붙습니다.
- 우상단 미니맵은 개편되어 진행 방향·목적지 경로·가게·**⛽ 주유소·🏪 편의점**을 항상 보여줍니다.
  미니맵을 탭하면 전체 지도가 열리고, `🧭 내비(진행 방향 위)` ↔ `N 북고정`을 전환할 수 있습니다
  (선택은 저장됩니다).

## 거리

- 지나가는 차량은 신호를 지킵니다. 적신호·황신호면 정지선 앞에 부드럽게 서고,
  초록불에만 출발하며 앞차가 서면 안전거리를 두고 줄을 섭니다.
- 보행자는 인도를 따라 걷습니다. 횡단보도 앞에서는 보행 신호(건너는 도로의 차량이 적신호)를
  기다렸다가 건너고, 빨간불이면 연석 앞에서 기다립니다.
- 주유소 2곳(중앙·남동쪽)과 편의점 2곳(중앙·북동쪽)은 지도에 항상 표시됩니다.

## 탈것 상점 (차고)

배달로 모은 수익(`localStorage` 저장)으로 탈것을 사고 바꿔 탈 수 있습니다.
탈것마다 최고속도·가속·코너링과 콕핏(계기판·카울 색)이 다릅니다.

| 탈것 | 가격 | 특징 |
| --- | --- | --- |
| 기본 배달 스쿠터 | 무료 | 125cc, 가볍고 무난 |
| 옐로우 클래식 | ₩9,900 | 노란 클래식 스쿠터, 속도·코너링 업 |
| 스포츠 스쿠터 | ₩34,000 | 고가속 250cc |
| 네이키드 투어링 | ₩89,000 | 최고속 최상, 바엔드 미러·전용 콕핏 |

## 구성

- `index.html` — 게임 전체가 들어 있는 단일 파일(HTML/CSS/JS, 빌드 불필요)
- `.nojekyll` — GitHub Pages에서 Jekyll 처리 없이 그대로 배포하기 위한 파일

3D 렌더링에는 [three.js](https://threejs.org/) r149를 CDN(jsDelivr → cdnjs → unpkg 순)에서
불러오므로, 플레이하려면 인터넷 연결이 필요합니다.
